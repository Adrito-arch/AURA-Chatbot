

\# AURA – AI Chatbot



AURA is an AI-powered chatbot built using Streamlit and LangChain, with OpenRouter integration.



\## Features

\- Interactive chat interface

\- Streaming AI responses

\- Conversation memory

\- New chat functionality

\- OpenRouter model integration

\- Secure API key configuration



\## Tech Stack

\- Python

\- Streamlit

\- LangChain

\- OpenRouter API



\## Run Locally



1\. Clone the repository.

2\. Install dependencies:



&#x20;  pip install -r requirements.txt



3\. Configure your OpenRouter API key in `.streamlit/secrets.toml`:



&#x20;  OPENROUTER\_API\_KEY = "your\_api\_key"



4\. Start the application:



&#x20;  streamlit run aura\_chatbot.py



\## Deployment

Deployed using Streamlit Community Cloud.
